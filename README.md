# 인스타 그라데이션 텍스트

사진 하단에 검정 그라데이션을 얹고 그 위에 흰색 볼드 텍스트를 넣어
인스타그램용 이미지를 만드는 모바일 웹앱. 단일 HTML 파일.

## 특징

- **서버 없음 / 업로드 없음** — 모든 이미지 처리는 브라우저 안에서만 실행됩니다.
- **여러 장 한 번에** — 최대 10장. 장마다 텍스트와 크롭을 따로 지정하고 순번이 붙은 PNG로 한꺼번에 저장. 썸네일의 × 로 잘못 고른 장만 빼고, 꾹 눌러 흔들리면 끌어서 순서 바꾸기
- **제목** — 첫 장에만 들어가는 제목. 나눔손글씨 하나손글씨, 크기·색상 조절, 배경 네모박스(모서리 10px) 넣기/색상 선택
- **비율** 1:1 (1080×1080) · 4:5 (1080×1350)
- **크롭** 드래그로 이동, 핀치·슬라이더로 확대/축소
- **그라데이션** 높이(20~70%, 기본 60%)와 진하기(0~90%, 기본 75%) 조절
- **텍스트** 나눔스퀘어 네오 Bold / ExtraBold / Heavy, 크기 조절(기본 55px), 엔터로 줄바꿈, 한 번에 지우기
- **저장** 미리보기 캡처가 아니라 원본 사진으로 고해상도 캔버스에 다시 렌더링한 PNG

비율·그라데이션·폰트는 **전체 공통**입니다. 캐러셀은 첫 장 비율에 나머지가 맞춰
잘리기 때문에 비율은 반드시 같아야 하고, 톤도 통일하는 편이 자연스럽습니다.

## 사용법

주소 접속 → 사진 선택(여러 장 가능) → 썸네일로 장을 오가며 크롭·텍스트 입력
→ 그라데이션·폰트 조정 → **전체 저장**.

iOS Safari에서는 저장 시트가 열립니다. **사진 앱에 저장 / 공유** 버튼을 쓰거나,
이미지를 길게 눌러 **‘사진에 추가’** 를 선택하세요.
여러 장은 파일명에 `-01`, `-02` … 순번이 붙습니다.

공유 버튼 → **홈 화면에 추가** 로 앱처럼 사용할 수 있습니다.

## 로컬에서 실행

`index.html` 파일 하나가 전부입니다. 브라우저로 그냥 열면 됩니다.
